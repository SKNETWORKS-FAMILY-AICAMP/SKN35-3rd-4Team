# 화면 실행 방법 (4번 · 화면)

> LangChain 버전 마이그레이션 코드 어시스턴트 챗봇 화면(`streamlit_app.py`)을 켜는 방법입니다. 루트의 `app.py`는 1번의 그래프 실행 시험용이라 다른 파일입니다.
> Windows PowerShell은 `&&`로 명령을 이어 붙일 수 없으니 **한 줄씩** 실행합니다.

**설치 없이 바로 보기 (배포)**: [https://migration-chatbot-ui-47wunvzaww7qc27nmwufvh.streamlit.app/](https://migration-chatbot-ui-47wunvzaww7qc27nmwufvh.streamlit.app/)  
배포 화면은 2번 데이터가 없는 버전이라 근거 ID와 자동 감지가 예시로 동작합니다. 실제 데이터로 보려면 아래처럼 팀 저장소에서 켭니다.

## 1. 처음 한 번

```powershell
uv sync
```

```powershell
uv pip install -r requirements.txt
```

| 패키지 | 쓰는 곳 |
|---|---|
| `streamlit` | 화면 전체 |
| `sqlalchemy`, `pymysql`, `certifi` | 대화 기록 저장 (TiDB) |
| `openai` | 연상 질문, 코드 없는 질문 답변 |

## 2. 비밀 값 넣기 (선택)

TiDB 접속 정보는 둘 중 편한 곳에 넣습니다 (`.env`가 먼저). 두 파일 모두 Git에 올리지 않습니다.

- 팀 `.env`에 아래 줄 추가 (팀 방식): `TIDB_HOST` · `TIDB_PORT`(4000) · `TIDB_USER` · `TIDB_PASSWORD` · `TIDB_DATABASE`(langchain_db)
- `.streamlit/secrets.toml.example` → `.streamlit/secrets.toml`로 복사: `[tidb]` (Streamlit Cloud 배포용)

| 값 | 없으면 |
|---|---|
| `OPENAI_API_KEY` | 연상 질문이 안 나오고, 코드 없는 질문에는 "키를 설정하면 답할 수 있다"고 안내 |
| TiDB 접속 정보 (`.env`의 `TIDB_*` 또는 `[tidb]`) | 내 컴퓨터의 `data/local_chat_history.db`(SQLite)에 저장 |

TiDB에는 팀 ERD대로 `langchain_db` 데이터베이스와 테이블(`users`, `chat_history`)을 만들어 둡니다. 테이블이 없으면 화면이 처음 켜질 때 같은 구조로 만듭니다.
Streamlit Cloud에서는 앱 설정 → **Secrets**에 같은 내용을 붙여 넣습니다.

## 3. 화면 켜기

```powershell
uv run streamlit run streamlit_app.py
```

브라우저가 자동으로 열립니다. 끌 때는 터미널에서 `Ctrl + C`.

## 4. 화면 구성

| 위치 | 내용 |
|---|---|
| 로그인 | **처음이에요**: 새 아이디 만들기 (한글 · 영문 · 숫자 · _ 2~20자, **가입 때 중복 검사**) / **이어서 하기**: 내 아이디로 들어가기 |
| 사이드바 | ChatGPT처럼 **새 대화**, **확인용 예제**(1.x로 올리기 30개, 고르면 그 버전으로 맞춰서 보냄), **내 대화 목록**(누르면 그 대화와 결과를 다시 불러옴), 로그아웃 |
| 질문 | 코드와 요청을 그대로 입력. **바꿀 버전은 글에 적음**(예: "0.2로 되돌려 줘"), 적지 않으면 최신 1.4.5. 버전 선택 상자는 없앰 (2026-10-15) |
| 진행 표시 | 기다리는 동안 그래프 단계(질문 분류 → 바꿀 부분 → 근거 → 고치기 → 검사, 실패하면 다시)가 실시간으로 |
| 왼쪽 채팅 | 옛 코드나 질문 입력, 답변 아래 이어서 물어보기 ([선택 기능] 연상 질문) |
| 오른쪽 결과 | 배지(검증 통과 · N회, 원래 버전 → 바꾼 버전) · 변환 기록, 탭: 전후 비교(빨강 · 초록) / 변경 사항 / 근거 / 검사 결과(11가지) / 코드 받기(.py · .md) / 안내. 실패하면 "같은 요청으로 다시 시도" 버튼 |

## 5. 저장되는 것 (TiDB)

| 테이블 | 열 |
|---|---|
| `users` | `uuid`(키) · `user_id`(로그인 아이디, 중복 금지) · `created_at` |
| `chat_history` | `uuid`(키) · `user_id` · `session_id`(대화방) · `question` · `answer` · `created_at` |

내 대화 목록에는 **내 user_id의 대화만** 나옵니다.

**세션 = 대화 하나**입니다. ChatGPT · Claude처럼 **새 대화**를 누를 때만 새 `session_id`가 생기고, 그 안에서 보내는 질문은 질문 + 답이 `chat_history` 한 행씩 같은 `session_id`로 쌓입니다. 채팅창 맨 위에 `세션 앞 8자리 · 시작 시각 · 질문 수`가 보입니다. 다시 연 대화는 질문 · 답만 보이고 결과 패널은 새로 보낸 코드부터 나옵니다 (ERD에 결과 열이 없음). 자세한 내용은 [DB_설계.md](DB_설계.md).

## 7. 자동 점검

```powershell
uv run python tools/bot_check.py
```

가입 · 아이디 중복 검사 · 로그인, **세션(질문 여러 개 → 대화 1개, 새 대화 → 새 세션)**, 버전 고르기 없음, 그래프 없을 때 시기 안내 5가지, **질문 36개 전부 실행**, 코드 붙여 넣기, 확인용 예제, 대화 저장 · 다시 열기, 사용자 분리까지 19가지를 임시 SQLite로 점검합니다 (TiDB · 유료 API 사용 안 함). 마지막 줄에 `19/19 통과`가 나오면 정상입니다.

## 8. 자주 나는 문제

| 증상 | 해결 |
|---|---|
| `ModuleNotFoundError` (streamlit, sqlalchemy, pymysql, openai) | 1장의 `uv pip install -r requirements.txt` |
| `'&&' 토큰은 이 버전에서 올바른 문 구분 기호가 아닙니다` | 명령을 한 줄씩 실행 |
| 사이드바 아래 "기록: SQLite(로컬)" | `.env`의 `TIDB_*`나 `secrets.toml`의 `[tidb]`가 없음. 2장 확인 |
| TiDB 연결 오류 (SSL, Access denied) | host · user(`<prefix>.root` 형식) · password, 데이터베이스를 먼저 만들었는지 확인 |
| 이어서 물어보기가 안 나옴 | `OPENAI_API_KEY` 없음. 2장 확인 |
| 근거 ID가 `sample-…`로 나옴, 또는 "1.x가 아닌 버전으로 바꾸려면 도구 목록이 필요" | 2번 데이터가 없는 폴더(개인 저장소 · 배포 화면)에서 실행한 것. 팀 저장소 최신 상태에서 실행 |
