# 화면 실행 방법 (4번 · 화면)

> 마이그레이션 챗봇 화면(`app.py`)을 내 컴퓨터에서 켜는 방법입니다.
> Windows PowerShell은 `&&`로 명령을 이어 붙일 수 없으니 **한 줄씩** 실행합니다.

## 1. 처음 한 번

프로젝트 폴더(팀 저장소)에서 실행합니다.

```powershell
uv sync
```

```powershell
uv pip install streamlit streamlit-agraph
```

| 패키지 | 쓰는 곳 |
|---|---|
| `streamlit` | 화면 전체 |
| `streamlit-agraph` | 시작 화면의 버전 마인드맵 (클릭해서 버전 고르기) |

## 2. 화면 켜기

```powershell
uv run streamlit run app.py
```

브라우저가 자동으로 열립니다. 열리지 않으면 터미널에 나온 주소(보통 `http://localhost:8501`)를 직접 엽니다.
끌 때는 터미널에서 `Ctrl + C`.

## 3. 화면 사용 순서

| 단계 | 하는 일 |
|---|---|
| ① 시작 | 마인드맵에서 옛 버전 상자를 클릭 (모르면 "모르겠어요" 상자 → 자동 감지). 마우스 휠로 확대 · 축소, 빈 곳을 끌어서 이동 |
| ② 목표 버전 확인 | LangChain 1.x와 현재 최신 버전을 보고 "확인하고 시작" |
| ③ 채팅 | 옛 코드를 붙여 넣거나 왼쪽 예제 버튼 클릭 → 오른쪽에 전후 비교 · 변경표 · 근거 · 진행 과정 |

## 4. 지금 화면이 쓰는 것

| 부분 | 지금 |
|---|---|
| 버전 · 숫자, 근거 ID(`imap-…`), 자동 감지 | 2번 데이터 (`data/processed/import_map.jsonl`, `src/rag/retrieval/`) |
| 코드 변환 결과 | 가짜 결과 (`src/ui/mock.py`). 챗봇이 연결되면 `src/ui/client.py`의 `run()`이 진짜 결과를 돌려줌 |

## 5. 자동 점검

버전마다 옛 코드를 넣어 화면 흐름을 끝까지 돌려 봅니다 (15가지).

```powershell
uv run python tools/bot_check.py
```

마지막 줄에 `15/15 통과`가 나오면 정상입니다.

## 6. 자주 나는 문제

| 증상 | 해결 |
|---|---|
| `ModuleNotFoundError: No module named 'streamlit_agraph'` | 1장의 `uv pip install streamlit streamlit-agraph` 실행 |
| `'&&' 토큰은 이 버전에서 올바른 문 구분 기호가 아닙니다` | 명령을 한 줄씩 실행 |
| 코드를 고쳤는데 화면이 그대로 | 터미널에서 `Ctrl + C`로 끄고 다시 `uv run streamlit run app.py` |
| 근거 ID가 `sample-…`로 나옴 | 2번 데이터(`data/processed/import_map.jsonl`)가 없는 폴더에서 실행한 것. 팀 저장소 최신 상태에서 실행 |
