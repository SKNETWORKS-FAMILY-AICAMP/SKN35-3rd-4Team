# 화면이 받고 싶은 결과 모양 (초안 · 상의용)

> 4번 화면이 챗봇에게서 받으면 좋은 정보입니다. **정해진 규칙이 아니라 1번 · 3번과 상의하기 위한 초안**입니다.
> 1번 State와 3번 결과가 정해지면 화면 쪽(`src/ui/client.py`)을 그 모양에 맞춥니다.

## 화면에서 보여 주는 것 → 필요한 정보

| 화면 | 필요한 정보 | 누가 만들 것 같은지 |
|---|---|---|
| 전후 비교 | 원래 코드, 고친 코드 | 3번 rewriter |
| 변경표 | 바뀐 줄마다: 옛 줄, 새 줄, 종류(native / classic_fallback), 대안 | 3번 (2번 근거를 바탕으로) |
| 근거 | 근거 ID (`imap-…`, `doc-…`), 문서 링크(문서 근거만) | 2번 검색기 → 3번이 전달 |
| 검증 배지 | 통과 여부, 시도 횟수, 실패면 이유 | 3번 verifier, 1번(다시 할지 판단) |
| 목표 버전 | 사용자가 확인한 버전 (지금은 1.x) | 화면 → 챗봇으로 전달 |
| 옛 버전 | 사용자가 고른 옛 버전, 또는 "자동 감지" | 화면 → 챗봇으로 전달 (검색 범위를 좁히는 데 쓸 수 있음) |
