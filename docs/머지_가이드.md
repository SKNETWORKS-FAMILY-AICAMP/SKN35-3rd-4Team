## 선택 기능 빼는 법

선택 기능은 모두 `src/ui/extras/` 한 폴더에 있고, 화면은 `src/ui/optional.py`의 `load()`로만 부릅니다.

| 빼는 방법 | 결과 |
|---|---|
| `src/ui/extras/` 폴더 통째로 빼기 | 화면은 그대로 동작. 연상 질문 · 코드 없는 질문 답변 · 버전 감지 안내 · 1.x 가 아닌 방향 변환만 빠짐 |
| 파일 하나만 빼기 (예: `followups.py`) | 그 기능만 빠짐 |

`streamlit_app.py`에서 선택 기능을 쓰는 곳은 `# [선택 기능: …]` 주석으로 표시해 두었습니다. 폴더를 빼면 그 부분은 자동으로 건너뛰므로 **코드를 지우지 않아도 됩니다**. 깔끔하게 지우고 싶으면 그 주석 사이만 지우면 됩니다.

2026-10-14 확인: `extras/` 폴더를 지운 사본에서 1.x 변환, 코드 없는 질문, 되돌리기 안내가 **오류 없이** 동작.

## 팀 저장소와 겹치는 파일 (2026-10-14 오후, dev `75143b8` 기준)

같은 경로에 있는 파일은 아래 4개뿐입니다. 나머지 내 파일(`src/ui/`, `eval/`, `tools/`, `docs/`, `.streamlit/`, `requirements.txt`)은 팀 저장소 어느 브랜치에도 없어서 충돌이 없습니다.

| 파일 | 상황 | 처리 |
|---|---|---|
| `app.py` | 1번이 dev 에서 그래프 실행 시험용으로 사용 중 | 2026-10-14: 화면 입구를 `streamlit_app.py`로 분리해서 **건드리지 않음** (dev 것 그대로) |
| `README.md` | 팀 README 와 내용이 다름 | **가져가지 않음**. 화면 설명은 `docs/화면_실행방법.md`에 있음 |
| `.gitignore` | 팀 것(파이썬 기본 + `data/vectordb`)과 내용이 다름 | **가져가지 않음**. 팀 `.gitignore` 맨 아래에 `.streamlit/secrets.toml`, `data/local_chat.db`, `data/local_chat_history.db` 줄만 추가 |
| `src/__init__.py` | 팀 것은 빈 파일 | 내 것도 빈 파일로 맞춤 → 같아서 충돌 없음 |

**2번 코드와 맞물리는 곳**: `src/ui/mock.py`가 2번의 `src/rag/retrieval/import_lookup.py`의 `lookup()`을 부르고, `data/processed/import_map.jsonl`, `data/raw/symbols/`를 읽기만 합니다. 2번 파일은 고치지 않습니다.

**확인 방법**: 최신 dev 를 그대로 받은 폴더에 내 파일을 덮어 놓고 점검 → `tools/bot_check.py` **29/29 통과**, `eval/check_questions.py` **35/35 통과**.

**예시 질문 겹침**: 1번의 시험 질문(dev `app.py`, ChatOpenAI + LLMChain + PromptTemplate, "양말")과 똑같던 질문 1개를 `eval/`에서 뺐습니다 (36 → 35개). 그 뒤 겹치지 않는 새 질문으로 바꿔 다시 36개 (1.x로 올리기 30).

**패키지**: 팀 `pyproject.toml`에는 `streamlit`, `sqlalchemy`, `pymysql`, `certifi`가 없습니다. 머지할 때 `uv add`로 넣어야 화면이 켜집니다 (`openai`는 followups 를 빼면 필요 없음). `pyproject.toml`은 1번 파일이므로 1번과 상의합니다.

## 배포 서버 (지금)

| 항목 | 지금 | 나중에 |
|---|---|---|
| TiDB 접속 정보 | 없음 → SQLite (재시작하면 기록 사라짐) | Streamlit Cloud 앱 설정 → Secrets 에 `[tidb]` 넣으면 코드 수정 없이 TiDB 사용 |
| OpenAI 키 | 없음 → 연상 질문 · 코드 없는 질문 답변 안 나옴 | Secrets 에 `OPENAI_API_KEY` (followups 를 가져갈 때만 필요) |
| 2번 데이터 | 없음 → 근거 예시, 1.x 가 아닌 방향 변환 안 됨 | 팀 저장소로 합치면 자동으로 실제 데이터 사용 |

즉 지금 배포는 **화면 동작 확인용**이고, 실제 데이터 · DB · 키는 팀 저장소에 합친 뒤 또는 Secrets 를 넣은 뒤에 붙습니다.
